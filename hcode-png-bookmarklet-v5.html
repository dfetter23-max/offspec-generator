📊 H/S Code PNG Report — Bookmarklet v5

Generates a PNG image from any H Code PDF report page. Captures both H-codes and S-codes.
v5 critical fix: Same y-coordinate on different PDF pages are unrelated — v4 was matching codes from any page to manifests on any page when their page-local y values happened to coincide. v5 now requires manifest and code to be on the same page. Also preserves literal NA values that some load reports type into the H Code column.
1
Drag this button to your Chrome bookmarks bar:
📊 Export H/S Codes PNG
↑ Drag this blue button up to your bookmarks bar and drop it there.
2
Navigate to an H Code report PDF page (URL ending in /$value).
3
Click 📊 Export H/S Codes PNG in your bookmarks bar.
A new tab opens with the report image and a Download PNG button.
How it works:
• Extracts every text token with its x/y coordinates and page number
• Locates the “H Code” column header and records its x-position
• For each manifest row, accepts a token whose page matches and whose x-position is within ±60 units of the header, matching ^([HS][A-Z0-9]+|NA)$
• Truly empty cells → N/A; literal NA entries are kept verbatim
• WTA still treated as N/A (unchanged)

Layout rules (unchanged from v3):
• Lines 1–4 → 1 row × 4 columns
• Lines 5–14, 15–24, etc. → 2 rows × 5 columns
• Empty/padding cells → blank
• Duplicate line numbers → first occurrence only
