📊 Install Visual H-Codes v12

One-time setup — turn long H Code reports into a clean visual grid.
Turn this
into this

H Code reports can run 5 to 10 pages, and when you're writing H-codes onto a manifest by hand, it's way too easy to put a code on the wrong line — or forget to leave a box blank for a crossed-out line.

This tool reads the entire H Code PDF and shows you exactly where each code goes, laid out in a grid that matches the manifest lines. No more flipping back and forth between pages, no more second-guessing which line you're on. It's faster and a lot fewer mistakes.

1
Drag this button to your Chrome bookmarks bar:
📊 Visual H-Codes
↑ Click and drag the green button up to your bookmarks bar and drop it there.
If you don't see the bookmarks bar, press Ctrl+Shift+B to show it.
2
Open an H Code report PDF in Chrome (URL ending in /$value).
3
Click Visual H-Codes in your bookmarks bar.
A new tab opens with the H-codes laid out as an interactive grid — click a block to highlight it, then use ↑ / ↓ to step through the rest.
Requirements:
• Must be run on an H Code PDF open in Chrome
• Only needs to be installed once — it stays in your bookmarks bar

What's new in v12:
• Frequency-ranked colors — H/S code colors are assigned by how often each code appears, so the codes you see most get the most distinct colors
• Left-side control panel — controls, zoom, and the manifest list stay fixed on the left while you scroll
• Manifest-list navigation with a Go back to Top button under the list
• Fixed black grid on every cell
• New look — navy outer background with a darker grey report area

Upgrading from an older version? Drag the new button onto your bookmarks bar and delete the old one — bookmarklets are baked in at drag time, so your existing bookmark still holds the old code.
