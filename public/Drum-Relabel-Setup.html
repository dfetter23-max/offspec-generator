Q Scanner Tool

iPhone setup — do this once on each phone

Scan with the iPhone Camera

or type in Safari:
ec-receiving.web.app/drum-relabel

  1. 1
    Scan the code
    Open the Camera, point it at the code, and tap the link that pops up. It opens in Safari.
  2. 2
    Tap Share
    The square with the up arrow at the bottom of Safari. Don't see it? Tap ••• first, then Share.
  3. 3
    Add to Home Screen
    Scroll down the list, tap Add to Home Screen, then Add.
  4. ✓
    Done
    From now on, just tap the Q Scanner icon on the home screen.

How it works

📱 On the phone

  1. 1
    Scan the drums
    With the normal Camera, take one photo of each fixed drum’s barcode, in order.
  2. 2
    Open Q Scanner
    Tap Choose photos and select all of the drum photos.
  3. 3
    Check it was sent
    Type in any red (unreadable) numbers. When the button says ✓ Sent to office, the list is on the office computer. No email needed.

🖥️ On the office computer

  1. 4
    Open Q Scanner Tool
    In the Q Manager Dashboard, left menu. The phone’s drum list is already there, in order.
  2. 5
    Copy the list into SAP
    Click Copy list, paste it into SAP’s multiple selection, and create the new labels.
  3. 6
    Save the labels as a PDF
    Don’t print from SAP. Save the labels as a PDF file instead.
  4. 7
    Drag the PDF into the tool
    Drop it on Q Scanner Tool, then Open to print. The labels print in the order the drums were scanned.
💡

Why save a PDF instead of printing from SAP?

SAP prints the labels in its own order, so they have to be matched to the drums by hand. Dropping the PDF into Q Scanner Tool puts every label in the same order the drums were scanned.
