How to Print from the Benzene Printer RED LABEL

Zebra ZT620 — printing a .ZPL label file from a USB flash drive

Before you start: you need the label file (it ends in .ZPL) from the Emergency Zebra Converter.
  • Put the file on the flash drive by itself — not inside a folder.
  • The drive must be 16 GB or smaller.
  • File names look like 90216-BAR.ZPL (load number, then BAR or CON).

1Plug in the USB drive

Plug the flash drive into the USB port on the front of the printer.

The screen should say PRINTER READY. If it doesn't, press ✕ CANCEL until it does.

2Open the Home Menu

On the PRINTER READY screen, press the top-left key — the one right under the house icon 🏠 on the screen.

The HOME MENU opens with 8 icons.

3Open TOOLS

Press ▶ until the word TOOLS shows at the bottom of the screen (it's the wrench-and-screwdriver icon, top row, second from left).

Then press OK.

4Go to PRINT USB FILE

Press ▶ 9 times.

Stop when the screen says PRINT USB FILE and shows a file name under it.

Went too far? Press ◀ to go back one screen.

5Pick your file and print

Press ▲ or ▼ until your file name shows on the screen. Check the load number matches.

Press OK to print.

6Check the first label

Make sure the label is lined up, then scan the barcodes on it before you use the rest.

When you're done, press ✕ CANCEL or the house key to go back to PRINTER READY, then pull out the drive.
