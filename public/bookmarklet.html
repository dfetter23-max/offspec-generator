LSR Grabber

v5 universal flow — popup-blocker safe

Bookmarklet that reads SAP Load Summary Reports and forwards the structured data to ec-receiving.web.app. v5 is a thin loader that pulls the latest extractor at click time — so any future fixes ship without you re-installing. Adds a persistent overlay with a clickable "Open Offspec Generator" button (so popup blockers no longer silently kill it), a file-picker fallback for when the in-tab read can't see the PDF, and a copyable diagnostic log when something still doesn't work.

Install

// drag the button to your bookmarks bar
★ LSR Grabber v5

If your browser hides the bookmarks bar, press Ctrl+Shift+B to show it, then drag. Or use Copy code instead and paste into a new bookmark's URL field.

How to use

  1. Open an LSR or Validation Error Report PDF in a browser tab — or skip ahead and just click the bookmarklet from any page; an overlay will appear with a Pick PDF from disk button as a fallback.
  2. Click the LSR Grabber v5 bookmark.
  3. The dark overlay in the top-right shows progress. When parsing finishes, click → Open Offspec Generator in the overlay. (Auto-open also fires when popups are allowed.)
  4. If the in-tab read fails or hangs, click Pick PDF from disk in the same overlay and choose the file. Same result — no bookmarklet reinstall needed for any future fix.

What v5 fixes

popup-blocker safe The v4 bookmarklet relied on window.open() as its only output. Some Chrome installs silently block that, so the extraction would finish invisibly. v5 shows a persistent overlay with a real <a target="_blank"> button — your click counts as user activation, bypassing popup blocking. file-picker fallback If the in-tab PDF can't be read (Adobe/Foxit extension hijacked the viewer, the PDF was downloaded instead of viewed, SAP auth blocked the fetch, etc.), the overlay always shows a Pick PDF from disk button. Pick the saved PDF — same parser runs. 10-second timeout If pdf.js getDocument() hangs (auth challenge, slow PDF, weird wrapper), v5 stops waiting after 10 s and surfaces the failure instead of the indicator just staying forever. multi-CDN pdf.js If cdnjs.cloudflare.com is blocked by a corporate firewall, v5 falls back to jsdelivr and then unpkg before giving up. clipboard backup Parsed JSON is also written to the clipboard automatically. If the overlay button doesn't open the receiving app, the user can still hit Paste from LSR on the dashboard. copy-paste diagnostics Failed extractions show a collapsible log with timing, errors, and UA. Click Copy log and send it back — no more "it just didn't do anything" with no clues. thin-loader bookmarklet The bookmarklet itself is now ~250 bytes. The real extractor lives at ec-receiving.web.app/js/lsr-grabber.js, so future fixes ship instantly — nobody needs to re-drag the bookmark.
