⋮⋮🏷️ Creating In-House Bar Code Labels

Stage 1 — VA02 (Sales Order)
  1. VA02 — enter monthly sales order.
  2. Create new item.
  3. Under Waste Profile, enter INHOUSE-____ — or use this tool to grab the Material # (just click on it in the table to copy).
  4. Under Order Quantity, enter the # of labels to create → ENTER.
  5. Delivery Block is now available — set to 40 - Initial Receiving → ENTER.
  6. SAVE.
Stage 2 — ZSD61 (Manifest)
  1. Go to ZSD61.
  2. Enter 4111 for plant.
  3. Change Class to PRINT.
  4. Enter the monthly Sales Order number → ENTER.
  5. Click the box in the table, then Create Manifest at the top.
  6. Manifest # = initials + date, e.g. DF05222024.
  7. For any signatures, put Y.
  8. Items tab — complete drum type and weight.
  9. Transporters tab — Page 1, Sequence 1, 28500010234, Y and date.
  10. Receivers tab — Y and date.
  11. SAVE.
Stage 3 — Back to VA02
  1. Back into VA02.
  2. Put Delivery Block on BLANK → ENTER.
  3. SAVE.
  4. Go back into VA02.
  5. Go to the last item and set Reason for Rejection to IN-HOUSE.
  6. SAVE.
  7. Print labels. 🏷️
Tip: leave this popup open while you click Material # buttons in the table — the popup stays out of the way on the right.
